# SHORTS PULSE

YouTube Shorts 후보의 조회수 변화를 브라우저에서 5분마다 추적하고, 확산 속도·최신성·반응률을 합산해 우선순위로 보여주는 크리에이터용 대시보드입니다.

## 핵심 기능

- 통계 5분 갱신: 이전 조회수 스냅샷 대비 시간당 증가량(VPH) 측정
- 후보 1시간 갱신: 국가·게시 기간·주제별 Shorts 후보 최대 50개 검색
- 급상승 점수: 증가 속도 55%, 최신성 23%, 반응률 17%, 실측 신뢰도 5%
- 태그, 원본 설명, 원본 영상 링크 및 독창적 대본 작성 가이드 제공
- API 키가 없을 때도 UI를 확인할 수 있는 명시적 데모 모드
- 반응형 다크 UI, 브라우저 로컬 저장(서버 DB 없음)

## 로컬 실행

외부 런타임 라이브러리가 없는 제로-디펜던시 앱입니다. [Bun](https://bun.sh/)과 TypeScript가 준비된 환경에서 실행합니다.

```bash
bun run dev
```

프로덕션 빌드:

```bash
bun run typecheck
bun run build
```

빌드 결과는 GitHub Pages의 브랜치 배포를 위해 `docs/`에 생성됩니다. 설치할 npm 패키지나 서버 의존성은 없습니다.

## YouTube API 연결

1. [Google Cloud Console](https://console.cloud.google.com/)에서 프로젝트를 생성합니다.
2. **YouTube Data API v3**를 활성화합니다.
3. API 키를 만들고, 애플리케이션 제한을 **웹사이트(HTTP 리퍼러)**로 설정합니다.
4. 배포된 사이트 주소와 로컬 주소(예: `http://localhost:5173/*`)를 허용합니다.
5. 사이트 우측 상단 **API 설정**에서 키를 입력합니다.

키는 `localStorage`에만 저장되며 저장소나 빌드 결과에 포함되지 않습니다. 검색 1회는 YouTube Data API 할당량을 비교적 많이 사용하므로 후보 검색은 1시간에 한 번으로 제한하고, 그 사이에는 저비용 통계 조회만 수행합니다.

## 공식 API 한계

- YouTube API의 `videoDuration=short`는 Shorts 여부가 아니라 짧은 영상 후보를 반환합니다. 앱은 현재 Shorts 최대 길이인 180초 이하로 추가 필터링하지만 세로 화면비는 API에서 제공하지 않아 일부 일반 영상이 섞일 수 있습니다.
- 임의 영상의 실제 자막 파일은 영상 소유자의 OAuth 권한 없이 `captions.download`로 받을 수 없습니다. 따라서 앱은 자막 원문을 가장하지 않고, 공개 메타데이터 기반 **내용 요약 + 독창적 대본 구조 가이드**를 제공합니다.
- 첫 수집에서는 과거 스냅샷이 없어 게시 후 평균 속도를 추정합니다. 5분 뒤부터 같은 브라우저에서 실측 증가량이 표시됩니다.
- 정적 사이트이므로 브라우저를 닫으면 백그라운드 수집도 멈춥니다. 24시간 서버 수집은 별도 백엔드·DB·예약 작업과 API 키 보안 설정이 필요합니다.

## 창작 및 권리 원칙

이 도구는 트렌드 조사용입니다. 원본 영상을 다운로드해 미세 변경 후 재업로드하는 용도가 아닙니다. 사실을 다시 검증하고, 직접 쓴 대본·직접 촬영한 화면·독자적 해설과 관점을 사용하세요. 원저작자의 저작권과 YouTube 재사용 콘텐츠 정책을 준수해야 합니다.
